# Logos

- `collector-mark.svg` — Three fanned cards; outlines `ink` #1f1d1a, back cards `surface-raised` #fffdf8, front `brand` #13595a, diamond `foil` #d9a03f. For light grounds. Favicons, app icons, tight spaces.
- `collector-mark-reversed.svg` — The same mark for dark grounds; outlines #efe9de, front #5fb7b2, diamond #e0ad52.
- `collector-wordmark.svg` — Mark plus "Collector" set in Fraunces 600 (outlined), text in `ink`. App header on light grounds.
- `collector-wordmark-reversed.svg` — The wordmark for dark grounds, text #efe9de.

All four are fixed-colour SVGs; they do not inherit CSS `color`.
